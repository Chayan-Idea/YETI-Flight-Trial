# PDF template assets

Each approved template must have its exact, unmodified source PDF stored in its own versioned folder, for example:

`assets/templates/IF_YETI_TD0_FTR_CKT_005/v1/source.pdf`

The matching package JSON must include the SHA-256 checksum of this exact PDF. The browser verifies the checksum before using the original PDF as the preview/export background.
